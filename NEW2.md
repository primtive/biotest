# Версия new2

Подготовлена 20 октября 2026 года. По просьбе владельца production на `vps-msk` **не обновлялся**. Новая сборка запущена только локально: http://localhost:3001.

## Изменения

- На главной показаны имя и логин текущего пользователя.
- Вход только по логину. Поля пароля убраны из формы входа, редактирования пользователей, API, Prisma и зависимостей. Миграция удаляет пользовательские `password`/`authVersion` и старую коллекцию `LoginThrottle`. Авторизация по ролям, запрет входа архивным пользователям и проверки Origin сохранены. Старые сессии требуют повторного входа.
- История пользователя, администратора и история в карточке ученика используют одну таблицу. Выравнивание, заголовки, пустое состояние и прокрутка на узком экране общие.
- История выбирается напрямую из MongoDB: сначала фильтр, сортировка и одна страница, затем только небольшие поля для строк. Пользователь и группа подгружаются для выбранной страницы. Дорогого Prisma join по всем тестам больше нет; ответы и снимки заданий в таблицу не передаются.
- Общие controls пагинации используются в истории, пользователях, темах, заданиях и отчётах: первая/последняя/предыдущая/следующая страницы, ввод номера и размер 10/20/30/50/100. Фильтры сохраняются в URL. Пользователи и темы фильтруются и выбираются страницами на сервере. API заданий возвращает страницу без массива обратных связей `testIDs`; ввод текстового фильтра задержан на 350 мс, устаревшие запросы отменяются.
- Отчёт передаётся в браузер страницами, с сортировкой по всему результату. Сам агрегированный результат отчёта кэшируется на сервере; вычисление полного рейтинга за период выполняется до разделения на страницы. Фильтры дат размещены компактно внутри карточек. На узких экранах элементы могут переноситься.
- В статистике вместо дат доступны вся история (по умолчанию) и учебные годы. Границы года: **1 августа 00:00 по Москве — 1 августа следующего года**, правая граница не включается. Начало и завершение теста учитываются по своим датам, включая переход между годами.

## Кэш статистики

`StatisticsCache` — постоянная коллекция MongoDB. Ключ включает пользователя/администратора, группу заданий и учебный год либо всю историю. В документе лежат итоговые счётчики и недельные ряды графиков.

`StatisticsRevision` — версия данных. Создание/завершение теста, изменение пользователей, заданий и тем увеличивают её; старый кэш больше не читается. Запись учитывает московскую дату, чтобы полная история правильно обновлялась при наступлении следующего дня. Одновременные одинаковые запросы в одном процессе объединяются. После перезапуска приложения сохранённый кэш продолжает работать.

В `Test` добавлены `taskCount`, `answeredCount`, `correctCount`. Новые ответы и завершение теста обновляют их в транзакции. Миграция считает значения по историческим флагам правильности, без повторной проверки ответов и без изменения баллов.

## Дамп

`/Users/alexey/other/dumps/biotest-dump-30.05.26-new2/`

Источник — свежая копия `biotest_v2` с production, восстановленная в отдельную локальную базу. Исходная локальная база и предыдущие дампы не изменялись. В new2 сохранены 303 пользователя, 13370 тестов и остальные бизнес-данные, добавлены индексы и 740 прогретых записей кэша. `migration-summary.json` содержит количество документов, SHA-256 и результаты проверки.

Проверено совпадение всех исходных документов после исключения только удаляемых парольных полей и добавляемых счётчиков тестов. Дамп полностью восстановлен в другую временную базу; содержимое всех коллекций и индексов совпало. Проверены Prisma и транзакции.

Для будущего развёртывания нужны **новая версия приложения и новая база вместе**: старый production-образ ожидает пароли и с new2 для входа не подходит. Инструкция `README.md` внутри дампа показывает восстановление в отдельное пространство имён.

## Миграция и проверки

- `scripts/migrate-v3.cjs` — отдельная миграция. CLI требует `--apply`, делает резервный архив до изменений и по умолчанию разрешает только localhost. Для удалённой базы требуется явный `--allow-remote`.
- `scripts/database.cjs` — полный repair; после восстановления старых данных применяет также миграцию v3.
- `scripts/export-new2.cjs` — экспорт из изолированной локальной базы с проверкой сохранения данных и повторным восстановлением; существующий каталог результата не перезаписывает.

```sh
npm run typecheck
npm run lint
npm test
npm run test:v3
npm run test:migration
npm run test:integration
npm run build
```

Тесты базы и API должны запускаться только с локальной тестовой БД и локальным сайтом. Они создают свои данные и очищают их. `test:v3` и `test:migration` используют отдельные одноразовые базы.

На полной копии выборка первой страницы истории из 20 строк заняла около 12 мс, сериализованный результат — 5247 байт. Это локальный замер на имеющихся данных, не нагрузочный тест VPS.
