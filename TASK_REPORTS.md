# Отправители жалоб

`Task.reportedByIds` хранит уникальные MongoDB ObjectId пользователей, отправивших жалобу. Отправитель берётся из серверной сессии. Повторные и одновременные запросы не дублируют пользователя; жалобы разных пользователей сохраняются вместе. При исправлении задания `isReported` сбрасывается, список отправителей сохраняется.

В админской таблице заданий кнопка «Жалобы» открывает список логинов и имён со ссылками на пользователей. Пользователи загружаются одним запросом только для текущей страницы заданий. Ученические страницы и API не раскрывают отправителей.

Для старой базы перед запуском новой сборки нужно однократно выполнить миграцию. Она связывает задания с `isReported: true` и пустым/отсутствующим списком отправителей с существующим пользователем **primitive_admin**. Известные отправители не перезаписываются. Повторный запуск безопасен. MongoDB не применяет миграции через `prisma generate`.

```sh
DATABASE_URL='mongodb://127.0.0.1:27018/biotest_new2_work?replicaSet=rs0&directConnection=true' node scripts/migrate-task-reporters.cjs --apply
```

CLI разрешает только localhost и перед изменениями сохраняет приватный резервный архив в `.local/`. Если `primitive_admin` не найден, задания не изменяются. Миграция проверена и выполнена только на локальной копии; VPS не использовался. Ранее подготовленный дамп `new2` не перезаписывался; для него также нужна эта миграция после восстановления.

Проверки: `npm run typecheck`, `npm run build`, `npm run test:integration`, `DATABASE_URL=... node tests/task-reporters.cjs` (только локальная MongoDB, отдельная одноразовая база).
